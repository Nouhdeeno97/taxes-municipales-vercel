# Sources officielles de déploiement

- Vercel, **Express on Vercel** : https://vercel.com/docs/frameworks/backend/express
- Vercel, **Deploying to Vercel** : https://vercel.com/docs/deployments
- Vercel, **Environment variables** : https://vercel.com/docs/environment-variables
- Vercel, **Using the Node.js Runtime with Vercel Functions** : https://vercel.com/docs/functions/runtimes/node-js
- Vercel, **Adding & Configuring a Custom Domain** : https://vercel.com/docs/domains/working-with-domains/add-a-domain

Ces références servent à contextualiser les limites d’un déploiement Express sur un environnement serverless, la gestion des variables et le raccordement DNS d’un sous-domaine.

## Hébergement mutualisé et serveur dédié

- Apache HTTP Server, **Reverse Proxy Guide** : https://httpd.apache.org/docs/current/howto/reverse_proxy.html
- Apache HTTP Server, **mod_proxy** : https://httpd.apache.org/docs/current/mod/mod_proxy.html
- cPanel, **How to Install a Node.js Application** : https://docs.cpanel.net/knowledge-base/web-services/how-to-install-a-node.js-application/
- cPanel, **Guide to Node.js Installations** : https://docs.cpanel.net/knowledge-base/general-server-administration/guide-to-node-js-installations/

Ces références fondent les procédures proposées pour l’hébergement mutualisé compatible Node.js, ainsi que le placement d’un proxy inverse devant l’application sur serveur dédié.
